# Food_Ordering_Management_System
## 📌 Overview
A multi-page Food Ordering System built using JavaScript OOP, demonstrating a real-world workflow: food selection, cart management, order review, payment processing, and real-time transaction simulation using Async/Await and DOM updates.


The project focuses on applying core JavaScript concepts such as:
- Classes & Objects
- Inheritance
- Asynchronous Programming (Promises, Async/Await)
- DOM Manipulation
- Event Handling

---

## 🎯 Features

### 🍕 Menu System
- Display list of available food items
- Dynamic rendering using DOM

### 🛒 Cart & Order Management
- Add items to cart
- Remove items from cart
- Calculate total price

### 💳 Payment Simulation
- Mock payment processing using Promises / Async-Await
- Success/failure handling

### 🚚 Order Tracking
- Real-time simulated order status updates:
  - Order Placed
  - Preparing Food
  - Out for Delivery
  - Delivered

### ⚡ Interactive UI
- Fully dynamic single-page application
- Real-time updates without page refresh
